MOB PIECE BATTLE フィギュア・タワー・ガチャ工房
2026-10-11 最新データ対応版

■ 起動
ZIP全体を展開し、MOB-PIECE-Editor フォルダ内の index.html を
Edge / Chrome などのブラウザーで開いてください。通信は不要です。
スマホのファイルプレビューでは動かない場合があります。

■ 取り込み済みのデータ
本体の現在の641体（画像・能力・実効スキル・融合レシピ）、19タワー、
239組の敵デッキ、5種類のガチャを収録しています。
敵デッキは本体が生成した現行デッキのスナップショットです。
編成ルールは45枚、Seed/Middleは同名3枚、MOBは同名1枚、段階配分自由。

■ 画像からフィギュアを追加
「＋ 画像から追加」で画像を選択またはドロップし、名前・段階・数値を入力。
追加すると詳細画面が開き、スキル、タグ、融合素材などを編集できます。
PNG / JPEG / WebP、入力20MBまで。長辺1200px以内に変換して保存します。
既存フィギュアも詳細画面の「画像を差し替える」で変更できます。
画像は下書きJSONにも含まれるため、元画像ファイルへの参照は不要です。
新規ID/UIDは自動発行し、その後は固定します。
「既存フィギュアから性能とタグをコピー」で名前・IDからコピー元を探せます。
段階・レア度・属性・ATK・DEF・攻撃種別・役割・スキル・タグを引き継ぎます。
名前とアップロードした画像は保持し、コピー後も数値を調整できます。
チェックを入れると融合条件とパッシブもコピーします。
融合レシピの召喚先とレシピIDは追加フィギュア用に自動設定します。
コピー元のフィギュアは変更しません。
新しいスキルの説明だけではゲーム内効果は実装されません。

■ タワー・敵デッキ・報酬
「タワー・ガチャ」→ タワーと階層を選択します。
コイン、ダイヤ、ルビー、報酬フィギュアを編集できます。
報酬は初回クリア時。1〜4階は対戦相手ごと、5階はマスター戦達成時です。
対戦相手を切り替えると、名前・ランクとデッキを編集できます。
フィギュアを名前で検索して追加、枚数変更、削除ができます。
45枚と同名上限、参照IDを画面内でチェックします。
編集中の不足や上限超過も下書きとして保存し、警告を表示します。

■ タワークリア後のガチャ
「ガチャ / 解放条件」で既存ガチャを編集、または新規作成します。
「登場するタイミング」で、最初から登場するか、どのタワーの5階クリア後かを選択。
名前・サブタイトル・ラインナップ・ピックアップ・メイン表示を編集できます。
追加したフィギュアも報酬、敵デッキ、ガチャに選択できます。
ガチャから削除したフィギュアはピックアップとメイン表示からも外れます。

■ 保存と復元
自動保存は、そのブラウザーと保存場所専用です。
「全編集データを保存」または「保存・出力」→「下書きJSON」でファイルを保存してください。
画像、追加フィギュア、タワー、ガチャ、編集前後のデータを含みます。
別の端末では「保存・出力」から下書きJSONを読み込みます（30MBまで）。
旧版の下書きも読めます。元データが異なる項目は三者比較を行い、
競合する値は現在値を残し、読込案を「未解決の読込データ」に保管します。
「1操作戻す」で直前の変更を取り消せます（履歴は起動中のみ、最大60操作）。

■ 本体への反映について
このエディターは編集・書き出し用です。本体やゲームセーブを自動変更しません。
編集後の下書きJSONまたは差分JSONを本体への反映作業に渡してください。
追加画像・報酬・ガチャ等をゲームで使うには、本体側への取り込みが必要です。
MOB-QUESTおよび受領した元ZIPは変更していません。

データ仕様の概要は editor-schema.json を参照してください。
