# フィギュア形成ガチャとSOUL

## ガチャ

1回と10連はそれぞれ1回の演出抽選を行う。排他的な区間で、全部SSR以上0.1%、メインピックアップ確定2%、通常抽選97.9%。
ピックアップ確定では最後の枠にメインを配置する。他の枠は従来の抽選。
全部SSR以上では全枠をSSR以上から抽選する（SSR:UR:MOB=15:4.5:0.5、存在するレア度で再配分）。
通常抽選でSSR以上が含まれるとSSR確定演出になる。含まれなければ通常演出。
単発の「全部SSR以上」はその1体が対象。10連は10体すべてが対象。
提供割合画面は保証を含む実効確率。演出プレビューは残高・所持数を変更しない。

src/data/summon-messages.json が演出文言の編集元。キーを残し、値を変更する。
npm run copy:sync、開発サーバー起動、ビルドでブラウザ用JSを生成する。
中心のMOB画像は icon/gacha.png。形成される画像は実際に獲得したフィギュア。

## テスト

SETTINGSのTEST MODEをONにして「全フィギュア所持」、または選択欄から「選んだフィギュアを25個所持」。
25個は再読み込み後も維持。OFFにすると通常所持上限に戻る。通常の獲得上限・ルビー変換、デッキの同名制限とCOSTは変更しない。
ガチャ画面のMAXボタンはテスト残高を9,999,999にする。

## MOB QUESTから移植した仕様

参照：隣のMOB-QUEST/js/game.jsの最終上書き、v174→v218の隣接定義、v218/v220のSOUL対象継承・複数能力、v221の対戦内使用済み管理。
既存v115の基礎能力・COST・同名制限、v133の個別5対5、v136の攻撃テンポは維持する。

- 共通の隣接タグを持つ隣同士のペアごとに能力補正と指定タグへのオーラを加算する。
- SOULはフィギュア自身のタグ種類数＋手札のSOUL加算タグ。最大10、効果段階は1/5/10。
- SOUL系タグのカウントは参照元どおり手札枚数。既存の通常タグ共鳴の「種類数」判定は維持する。
- 1ラウンド最大2種類を選択。CPUも最大2種類。同じフィギュアは対戦全体で1回、0体を選んで温存できる。
- 選択後にカットイン、能力反映、戦闘開始。数値効果強化・味方全体・自分・センター・敵全体・敵単体と節をまたぐ対象の継承を実装する。
- HP上昇は最大HPと現HP比率を維持。HP低下は最大HPを維持して現HPを減らす。参照元の「正面の敵」は先頭の生存敵。
- データ内の「全ステータス」はHP/ATK/DEF/SPDに展開し、表記どおりに反映する。
- 図鑑・ガチャ詳細・バトル準備の詳細に、SOUL各段階と隣接効果を表示。

RPGのMP、魔法、装備、探索、育成+9を個別5対5へ混入させない。バトル専用のpieceSoulデータを使用する。
