# 初期スターター3種・ガチャ3種

2026-10-04。採用済みBFX24体と既存承認キャラだけを使用し、旧22ガチャと暫定SELECTED-BFXを提供対象から外した。旧データ・画像・所持品は削除しない。最新の手札スキル、融合、効果音を維持する。

## 初回選択と旧セーブ

新規プレイヤーには3択を表示し、選んだ1種類の45枚に必要な所持数だけを付与する。確認前・戻る・再読込では付与しない。保存成功時にのみ受領済みへ進む。新規プロフィールの展示とアバターは選択デッキのキャラに設定する。

既存プレイヤーは任意で1種類を受け取れる。既存所持数を減らさず、不足数だけを補う。保存済みデッキ・選択中スロット・展示・通貨・対戦履歴・過去のガチャ結果を保持する。空きスロットへデッキを保存し、全5枠が埋まっていれば所持品の補完だけ行う。初回選択の再受領は不可。デッキ画面の3テンプレートは所持数が揃った場合だけセットでき、追加付与はしない。

旧11スターターの定義と旧無料移行関数は互換検証用に残しているが、通常の起動・選択フローから一括無料配布を呼ばない。新規向けの提供テンプレートとCPUの選択肢は3種。所持済みの旧キャラは引き続き使える。

## ガチャ

各50種。採用24種は3ガチャ共通、既存26種とPUはテーマごとに選択。全レア度の枠を維持。通常R50/SR30/SSR15/UR4.5/MOB0.5％、既存の特殊抽選と10連保証・個別PU計算をそのまま使う。1回MOB5、10連MOB50。所持上限R15/SR12/SSR7/UR4/MOB2、超過は従来のルビー変換。表示個別確率の合計100％を検証。

旧ガチャは表示・新規抽選・交換対象から除外。保存された旧bannerIdは新しい先頭バナーへ切り替えるが、旧lastDrawの内容は保持する。収録されていない旧キャラは今回の3ガチャから新規入手できない。所持品からは利用できる。

## バナー

SWEET BEAT STREETは既存の採用キャラ画像を使用。RETRO REMIX JAMはBFX019/042、MIDNIGHT SUGAR LIVEはBFX023/050の2体を用いたHTML暫定表示。未採用キャラ入りの旧画像を表示しない。

完成2PNGのLibrary取得は正規ヘルパーがWindowsのos.setxattr未対応で失敗したため、未導入。最小配置先は本体gacha/retro-remix-jam.pngとgacha/midnight-sugar-live.png。原本がこのPCで読めたら画像を確認し、initial-release.jsonの各imageを対応パスに設定して再ビルドする。勝手なダウンロード迂回や未読画像の有効化は行わない。

## データと検証

主定義src/data/initial-release.json。選択処理src/game/initial-release.js、画面src/screens/initialStarter.js。ガチャ提供はsrc/data/gacha.js、旧履歴の読込互換はsrc/game/profile.js。

npm testにinitial-release-checkを追加。3デッキの45枚・上限・全融合先、実CPU対戦、3プール・確率・保証・コスト・上限・旧提供拒否、初回/既存/満杯スロット/保存失敗を確認する。test:initial-uiはEdgeで選択戻る・再読込・保存失敗後の再試行・旧セーブ保持を検証する。test:audio-uiとtest:tactical-uiも継続する。

バックアップ：作業フォルダbackup-before-three。変更前ハッシュthree-baseline.jsonと適用後three-applied-files.jsonで、音・戦術を含む今回対象外のファイルが維持されたことを確認する。commit/push/公開/セーブ初期化なし。
