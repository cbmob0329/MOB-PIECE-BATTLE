# 手札表示・閲覧操作・編集アプリ同期

取得版: `78c72dc70134e47ace2e01fa8b3603d254de1f5f`。今回はゲーム効果・数値・タグ・編成データを変更していない。

原因: 手札画像の高さ計算が残回数欄追加前のままで、カード名と数値欄が押し合っていた。場の単タップが `materials=[selected]` も設定し、詳細を閉じた後やバトル中にも素材選択の案内を残していた。旧編集アプリは版違いを警告しても `records` 全体を置換していた。

変更: 手札を画像・名前・ATK/DEF・短い残回数の独立行へ。横スクロールは手札内だけ。場の通常選択と移動選択を分離し、詳細表示・閉じる・スキル確認・フェーズ切替で素材指定を解除。先攻制限は共通ボタンにも反映。融合処理・攻撃処理は既存エンジンを継続使用。

操作: 場を単タップで選択し「性能」または同じ個体をダブルタップして詳細確認。融合はメイン中に「場を選択→移動→別の味方か手札」をタップし確認。手札→場とドラッグも可能。「戻る」「閉じる」で素材指定解除。バトル中は味方選択→相手タップ→攻撃確認で、素材モードは起動しない。

エディタ: 641体・118タグ・269レシピ、最新の実効スキル（個別runtimePlanを含む）・常時能力・画像を同期。旧編集JSONの `changes/base/edited/fields` だけをフィールド単位で三者比較。古い全recordsは上書きしない。競合は現在値を保持し、編集案を `unresolvedImports` に保存。baseなし別版・未知IDも未適用で保持。独自効果は自由記述・実装待ちのまま。画像内蔵 `editor-current-snapshot.json` の読込と本体スナップショット出力を追加。取り込んだ基準データはIndexedDBへ保存、従来の下書きキーは保持。

検証: Edge 320/390/430px、実際の長名と15枚の表示フィクスチャ、連続詳細・ダブルタップ・移動指定／取消・融合選択／取消・先攻エンド→CPU→バトル移行・バトル中の詳細を確認。エディタをfile://で起動し、数値・編集保存・再読込・最新snapshot取り込み後の編集保持と再読込を確認。旧627体からの安全な差分統合、競合、patch単独、全データ往復、画像内蔵、独自効果の未実装表示も検証。スキル回数8項目と演出状態回帰成功。

ビルド: 既存破損出力先を避けた新規領域で成功。1292素材をSHA256照合。作業フォルダー `isolated-production-latest.json` と `ui-editor-evidence/report.json` 参照。

未検証: iOS/Android実機、物理IME。長名の全文は詳細画面で確認でき、手札内の名前は2行まで。画像内蔵snapshotは約19MB。通常のsnapshot出力でassets参照がある場合はZIP全体を持ち運ぶ。ゲーム本体への編集差分自動適用は行わない。commit/push/公開なし。
