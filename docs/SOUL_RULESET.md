# MOB SOUL BATTLE 確定マスター v1（2026-10-02）

## 優先関係と出典

ユーザー指定の ZIP 内 JSON を実性能の正とする。旧自動生成データ・旧 handoff の性能より優先する。MOB STORY 本体と、その中の旧モブピースバトルには変更を加えない。

原本4ファイルは handoff/soul-v1/ に保存。実装データは src/data/soul-catalog.js、インポーターは scripts/import-soul-master.mjs。ATK/DEF・階級・属性・新作タグ・スキル効果・融合条件はJSONからコピーし、性能の推測・再調整を行わない。元の効果文と sourceBasis を保存する。102個の完全一致する効果文に、明示的な実行プログラムを割り当てる。未知の文章はインポート時エラーにする。

327体：シード231、ミドル74、MOBソウル22。通常融合192ルート、特殊融合10ルート。sourceTags は資料用、実戦は gameTagIds のみ。

ユーザーがこの会話で承認した追加事項：
- クフレイ：任意属性扱いに加え「このスキル使用後も、このターンはフュージョン素材にできる」を明記。
- モブフェニックス：撃破時の帰還スキルで手札に戻った個体は、ミドルでも直接再召喚できる。次の召喚時DEF+30。一般のミドル直接召喚は不可。
- 山札切れ：必要なドローができないプレイヤーが敗北。

## 戦闘

- 45体（シード30・ミドル10・MOB5）。通常ドローはシードだけ、上位階級は専用領域。
- LIFE400、場3枠。手札を5体へ補充。空き枠があれば召喚回数制限なし。
- メインで通常スキル・召喚・融合。バトルへの移行後はメインへ戻れない。
- ATK>DEFで撃破、差分をLIFEへ。ATK<=DEFならダメージ0・無撃破。ただし、データで明記された等値撃破などの例外は適用する。
- 直接攻撃は禁止。原則1体1回攻撃。2/3/5回攻撃、撃破による追加攻撃、各相手へ1回ずつの攻撃は明記されたスキル使用時だけ。
- 両プレイヤーが各ターン1回ずつスキル使用権を持つ。攻撃宣言・相手スキル発動・撃破で一旦処理を止め、対応スキルを使うか見送るか選択する。対応スキルも使用権を消費する。
- 使用者は同ターン素材にできない（クフレイのみ例外）。手札帰還・再召喚で同ターンの素材禁止を回避できない。
- スキルの対象、戻す手札・撃破済みシード、検索するシード、追加/無効化するタグ、移動先を選択できる。
- 「次の相手ターン終了まで」「次に攻撃するまで」「次に撃破される時」の持続を個別管理。指定のない一時的な能力変化は従来どおり発動ターン終了まで。LIFE回復上限400。
- 再召喚時DEF+30はその個体が場を離れるまで保持。帰還により特殊融合の強化は失われる。
- 手札は編成順でドロー。会心、確率回避、シャッフル等の新しい乱数要素を追加しない。

## フュージョン

通常：シード2体→ミドル、ミドル2体→MOB。指定の属性・タグ・特定名によるレシピを使用。専用領域の対象を消費し、素材を墓地へ送る。撃破済みシード回収スキルで融合素材は回収しない。

特殊：指定10ペアに一致する場合だけ MOB SOUL FUSION を選べる。通常融合とは別ボタン。ATK+20/DEF+20は場を離れるまで持続し、専用バナーと場の発光を表示する。覚醒リリス四姉妹の素材にモブリリスは使わない。直接攻撃などの追加効果なし。
