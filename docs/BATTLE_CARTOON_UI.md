# Battle UI / cartoon fields

2026-10-02. Built-in image generation edited the three field backgrounds into bold outlined, cel-shaded cartoon art. Final files: `public/battle-art/{inferno,ice,verdant}.png`. Existing battle rules and authoritative figure data retained.

HOME → バトルをカスタマイズ selects one of three fields and three deck cubes. Choices save automatically. Battle supports hand-to-slot summons, figure-to-figure drag fusion with confirmation, formation effects, attack/guard effects, response skills, speed toggle and skip.

Validated: regression suites (including 28 master checks), production build, 390×844 browser summon and drag fusion. Screenshot: `docs/battle-cartoon-mobile.jpg`.
