# BATTLE効果音の質感改善

対象はBATTLEのみ。STORY、PARTY、デッキ、スキル性能、フィギュアデータは変更していません。
自作の決定的PCM合成を継続。音程を並べるベル／サイン波中心の共通音を、帯域制限ノイズと短いノイズ励振共鳴に置換しました。

|属性|攻撃・スキル・融合の主な質感|
|---|---|
|炎|既存の炎設計を短い噴出、燃焼、火の粉に整理|
|水|広がる飛沫、細かな水滴、短い空洞共鳴|
|雷|短い放電連打、帯域を抑えた亀裂、低い余韻|
|地|岩の打撃、粒状の破片、短い胴鳴り|
|風|風切り、低い空気の尾|
|光|柔らかな散乱音と短い非整数倍の共鳴|
|闇|中低域の渦、短い濁った共鳴|
|無|中域の打撃と空気の衝撃|

既存4混合属性は各属性を平方根で減衰して混合。物理は打撃を追加、魔法は属性の質感を中心にし、融合は集合と胴鳴り、特殊／回復は短い共鳴を追加。小中大は既存の長さ・ピーク段階を維持します。

|イベント|発音位置と内容|
|---|---|
|攻撃|演出開始から風切り→50%で属性衝撃。CSSのimpact 42–60%、recoil 48–60%に対応|
|スキル|溜め→35%で発動（portraitの拡大位置）。結果hitは別イベント|
|融合|集合→60%で主音。素材消失55%、本体出現65%の間|
|召喚|形成→78%で着地音。body／platformの82%付近|
|ドロー|20%で紙の擦れ。カード表示開始位置|
|着弾／防御／撃破|各イベント開始時に打撃／盾／破片|
|UI・編成|短いクリック・木質の共鳴。追加／削除／エラーの高さと回数を区別|
|開始・ターン・終了・勝敗・報酬|短い打撃と共鳴。勝敗は上昇／下降する短い3打|
|ガチャ6段階|既存の段階呼出しを維持し、集合・組立・着色・出現の素材音へ|

長い演出でも1つのキャンセル可能なPCM内に溜め・発動・着弾を配置。演出の実時間を渡すため、短縮／敵ターンも比率が一致し、独立タイマーは増やしていません。音量・mute保存、6音上限、連打抑止、scope停止、iOS unlock経路は既存を維持。
