- 1–4Fは2勝先取。5Fは3デッキを5戦へ事前割当、各2回まで、3勝で終了。
- 編成スナップショットと連戦結果を保存。中断した試合は最初から再開、完了した試合のスコアは保持。

- Fは45Seed、融合・強化・能動/応答スキル禁止、自動発動能力なし。全階の敵カードは草原MB系のみ。
- 別ID強化は属性またはタグ一致でATK/DEF各+15、両方一致で各+30。同IDは各+30。1回の融合内で重複加算しない。後続の合法な強化では選んだ個体へ加算。
