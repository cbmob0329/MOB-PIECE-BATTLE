# ガチャ開封演出の修復

当選したフィギュア自身の透過PNGから、黒いシルエット、白い輪郭、未塗装パーツ、完成カラーを生成する。別キャラや四角い枠で代用しない。画像が読み込めない場合は再試行とスキップを表示し、確定済みの抽選結果を保持する。

通常は黒い発光シルエット → 2.3秒から未塗装パーツの形成 → 5秒から下から上への着色 → 7.8秒で完成表示。演出軽減設定でも順番を保ち、移動を抑えて3.6秒で完成する。レアリティで光と効果音の強さを調整し、輪郭の光は点滅させない。形成・着色の開始と対応する効果音を同期した。

Escapeは確定済み結果へスキップする。終了・画面移動時にはタイマー、描画、効果音を破棄する。抽選・付与・セーブ処理は変更していない。既存3ガチャ、3初期デッキ、24体の選定、戦闘スキル、音声設定は維持した。
