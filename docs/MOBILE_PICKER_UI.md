# BATTLE：一覧・5エース選択のスマホUI改善

対象：`C:\Users\user\Documents\GitHub\MOB PIECE BATTLE`。ローカル実装のみ。

## 操作

- 「エース5体から編成」を開くと、下部に選択数（0/5〜5/5）、選択済み5枠、編成案ボタンを常時表示します。候補部分を独立してスクロールできます。
- 下部のサムネイルを押すと選択解除。5体になるまで決定できず、6体目は選択できません。検索で候補を絞っても選択は保持します。
- 閉じて開き直した場合も、同じ画面セッション・同じデッキ枠の選択と絞り込みを保持します。ページ再読み込みで選択途中の状態は消えます。編成案を確認して反映するまでデッキは変更しません。
- FIGURE一覧とエース候補の星でお気に入りを登録・解除できます。両画面で「お気に入りだけ」と名前・ID・タグ検索、タグ絞り込みを併用できます。
- エース候補は従来どおり所持数・DECK 1/2の予約を考慮します。お気に入り登録によって未所持フィギュアを編成できるようにはなりません。
- 確認画面の反映ボタンも固定操作部へ移動。safe-areaとVisual Viewportに追従し、低い画面でも本文をスクロールして操作できます。

## 保存と互換性

既存のセーブキー・バージョンを維持し、`favoriteFigureIds`を追加しています。旧セーブでは空配列として読み込みます。IDで保存し、重複や不正な型を除去します。所持・デッキ・ゲームルールは変更しません。

お気に入りの更新はプロファイルのコピーを保存してから反映します。保存に失敗した場合は元のセーブ・メモリを維持し、エラーを表示します。星ボタンはカード詳細・エース選択と分離されています。
