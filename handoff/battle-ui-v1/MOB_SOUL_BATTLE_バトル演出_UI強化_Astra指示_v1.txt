MOB SOUL BATTLE
Astra実装指示書：バトル演出 / UI / レイアウト / デザイン強化 v1

==================================================
■目的
==================================================
MOB SOUL BATTLE のバトル全体を、
「最新スマホゲームとして十分通用する、見栄え・分かりやすさ・気持ちよさを兼ねた高品質バトル体験」へ引き上げてください。

今回は単なる機能実装ではなく、
UIデザイン
配置
アニメーション
演出
情報の見せ方
操作感
カスタマイズ性
まで含めた大型強化です。

「カートゥーンフィギュアバトル感」を最優先してください。

ログ風にテキストが流れるだけの地味な見せ方は禁止です。
必ず、状況に応じた見やすいメッセージUIと派手で分かりやすいアニメーション演出を実装してください。

この指示書に添付されている参考画像は、
レイアウト・UI・演出・雰囲気・装飾密度・見せ方の方向性参考です。
完全コピーではなく、MOB SOUL BATTLE 用に統一感ある完成度へ落とし込んでください。

==================================================
■最重要方針
==================================================
1. カートゥーンフィギュアのコレクションバトルらしさを強く出す
2. 情報は多くても、直感的で読みやすくする
3. 演出は豪華にするが、操作不能時間が長すぎないようにする
4. 各フェイズで「今なにをすればいいか」が分かる
5. HOMEで見た目カスタマイズできる楽しさを強化する
6. UIパーツを安っぽくしない。スマホ向けの高級感が必要
7. 既存ゲームルールは保持しつつ、見た目とバトル体験を大幅強化する

==================================================
■バトル画面 全体レイアウト
==================================================
スマホ縦画面前提。

画面構成は以下を基本とする。

【上部HUD】
・左上：自分プレイヤー情報（名前、アイコン、LIFE、必要なら小さな状態表示）
・右上：相手プレイヤー情報（名前、アイコン、LIFE、必要なら小さな状態表示）
・中央上：TURN表示、現在フェイズ表示、ターン進行感のある豪華なエンブレム
・上部左右または上下に、デッキ枚数・墓地枚数を視認しやすく配置

【中央：メインバトルフィールド】
・上段：相手フィールド3枠
・下段：自分フィールド3枠
・各枠は単なる四角ではなく、フィギュアを置く“ディスプレイ台座”感・ホログラム召喚台感のある豪華な見た目
・自分側・相手側が一目で分かる色分け
・フィールドマットの個性がしっかり見えるようにする

【中央下：メッセージエリア】
・ログではなく、その場の状況を大きく伝えるメッセージウィンドウ
・例：
  - 「ドロー！」
  - 「召喚できます！」
  - 「ソウルフュージョン！」
  - 「ATK 180 VS DEF 120」
  - 「撃破！」
  - 「勝利！」
・メッセージはキャラクターアイコン付きでもよい
・毎回大げさすぎず、テンポを阻害しない

【下部：操作エリア】
・手札を横並びで大きく見せる
・その上または近接位置にフェイズ操作ボタン群
  - ドロー
  - 召喚
  - ソウルフュージョン
  - バトル
  - エンド
・一番押してほしい現在行動ボタンは強く発光・拡大気味
・デッキ・墓地ボタンも下部の分かりやすい位置に配置してよい

==================================================
■フェイズごとの強化内容
==================================================

--------------------------------
1. バトル開始
--------------------------------
・試合開始時は短いが気持ちいい開幕演出を入れる
・プレイヤー名、LIFE 400、VS構図、フィールドマット、代表フィギュアが映る
・重すぎない程度に豪華
・「BATTLE START」または「バトル開始」バナーを強く見せる
・開始時、画面が一瞬引きでフィールド全体を見せてから通常バトル画面へ入る

--------------------------------
2. ドロー
--------------------------------
・カード/フィギュアを引く瞬間を気持ちよくする
・デッキキューブから光が走る
・カードが1枚飛び出す、もしくはホログラムフレームに吸い込まれるように手札へ追加
・「ドロー！」のメッセージ表示
・手札追加時に軽い弾み・発光・音感のある見せ方

--------------------------------
3. 召喚
--------------------------------
・ユーザー要望最重要
・フィギュアが“形成される”ようなカートゥーンホログラム演出を入れる
・手札からフィギュアを場へ出すと、まず召喚台座に青白いまたは属性色のホログラム線画・ワイヤーフレームが形成される
・その後、フィギュア本体が立体感を伴って実体化する
・最後に台座へ着地、軽いバウンドまたはポーズ決め
・「召喚！」または「召喚完了！」メッセージを見せる
・召喚されたフィギュアのATK/DEFや属性などの小表示が分かりやすく出る

--------------------------------
4. ソウルフュージョン
--------------------------------
・ユーザー要望最重要
・操作：フィギュアを掴んで移動し、別の素材フィギュアへドラッグして重ねる
・確認ダイアログは表示する
  例：
  「ソウルフュージョン」
  「この2体を融合させますか？」
  [キャンセル] [融合する]

・演出：
  1. 2つの素材フィギュアが台座ごと軽くカタカタ震える
  2. 2体が中央へ吸い寄せられる
  3. 3D風にクルクル回転しながら光に包まれる
  4. 光輪・渦・エネルギー線・属性色エフェクトを重ねる
  5. 形成シルエット → 完成フィギュア実体化
  6. 完成フィギュアがドンと着地
  7. 「SOUL FUSION」または「ソウルフュージョン！」の豪華バナー表示

・通常フュージョンとMOBソウルフュージョンは演出差をつける

【通常ソウルフュージョン】
・十分派手
・青・金・属性色中心の演出

【MOBソウルフュージョン】
・特別感を強く出す
・専用の「MOB SOUL FUSION」バナー
・通常より大きい閃光、発光、衝撃波、豪華な着地
・召喚後もしばらくフィギュアが強く輝く
・JSONで指定済みの ATK+20 / DEF+20 を表示面でも分かりやすく見せる
・特定モンスター×特定モンスターの特別召喚だと一目で分かるようにする

--------------------------------
5. バトル
--------------------------------
・攻撃宣言時、「ATK ○○ VS DEF ○○」をしっかり見せる
・攻撃するフィギュアが前進または飛び込み、対象にぶつかる
・斬撃、打撃、魔法弾などフィギュア個性に応じて軽く差別化できると望ましい
・ヒット時に大きなインパクト、フラッシュ、揺れ、数字演出
・撃破時は破片、光の粒、ホログラム崩壊、魂が抜けるような退場など、フィギュア感を壊さない演出
・差分ダメージがプレイヤーLIFEへ入る時は、LIFE表示側へエネルギーが飛ぶようにする
・複数回攻撃や全体攻撃スキルがある場合も見栄えよく分かりやすく実装

--------------------------------
6. エンド
--------------------------------
・ターン終了時は小さくまとまりすぎない
・「エンド」または「ターン終了」表示を短く出す
・次プレイヤーのターンへ自然に切り替える
・フェイズUIが次の状態へ変化する演出を入れる

--------------------------------
7. 勝敗
--------------------------------
・勝利時は爽快で豪華
・「WIN」または「勝利！」バナーを大きく表示
・代表フィギュアが勝利ポーズ
・紙吹雪、光、報酬アイコンなどで盛り上げる
・次へ進みたくなる画面にする

・敗北時も安っぽくしない
・「LOSE」または「敗北」表示
・再挑戦や戻る導線を明確にする

==================================================
■UIデザインの方向性
==================================================
・高級感あるカートゥーンモバイルゲームUI
・濃いめのベースカラー＋発光アクセント
・金属フレーム、クリスタル、属性エッジ、ホログラム、王冠、エンブレム表現と相性が良い
・フィギュアの台座感・コレクション感・ディスプレイ感を意識する
・カードゲームUIすぎず、「フィギュアバトル」らしさを前面に出す

フォント・表示方針：
・太く読みやすい
・重要数字（LIFE / ATK / DEF / DECK / 墓地）を見失わない
・説明文は読みやすく簡潔に
・ログ風の細かいテキスト連打は禁止

==================================================
■手札デザイン
==================================================
・手札は見ていて楽しいように大きめで魅力的にする
・カード枠ではなく「フィギュアデータカード」「フィギュアスロットカード」感でもよい
・属性色、レア度色、コスト、ATK/DEF、名前が見やすい
・選択中の手札は大きく浮く、光る、少し拡大
・ドラッグで召喚しやすい操作性を確保

==================================================
■デッキキューブ
==================================================
デッキは通常のカード束ではなく「正方形のキューブ」デザインを採用する。
これはHOMEで変更可能な見た目カスタマイズ要素。

初期デザインをまず3種導入する。

1. 炎のヒーロー
・赤 / 橙 / 金
・ヒロイックで熱い印象
・炎や王冠モチーフ

2. 氷晶のガーディアン
・青 / 水色 / 銀
・クールで神聖な印象
・氷結晶や城塞モチーフ

3. 闇のソウル
・紫 / 黒 / マゼンタ
・妖しく強い印象
・髑髏、影、渦、闇結晶モチーフ

・HOMEで変更できること
・将来的にショップ等で追加購入できる前提なので、差し替えしやすい実装にすること

==================================================
■墓地デザイン
==================================================
・墓地もアイコンだけでなく、ちゃんと存在感を持たせる
・ただし主張しすぎない
・デッキキューブと並んでも見劣りしない質感にする
・髑髏、封印石板、ソウル保管装置、闇ホログラム端末など、世界観に合う方向で高級感を出す
・枚数/体数が分かる

==================================================
■フィールドマット
==================================================
フィールドマットもHOMEで変更可能な見た目カスタマイズ要素。
初期デザインを3種導入する。

1. 煉獄の大地
・赤 / 黒 / 溶岩
・激しい熱量

2. 氷晶の城塞
・青 / 水色 / 氷 / 城
・クールで神秘的

3. 緑風の遺跡
・緑 / 石 / 遺跡 / 自然
・明るく爽やかだが戦場として成立する見た目

条件：
・自分3枠 / 相手3枠が見やすい
・敵フィールド / 自分フィールドが一目で分かる
・フィギュアが乗った時に映える
・台座、発光ライン、置き場が背景に埋もれない

==================================================
■HOMEでのカスタマイズ
==================================================
HOMEから変更可能にする。

カスタマイズ項目：
・デッキキューブ
・フィールドマット

UI条件：
・プレビューが見やすい
・現在の装備デザインがすぐ分かる
・変更時に即時反映または分かりやすい確認がある

==================================================
■メッセージ表示
==================================================
基本はログではなく、ちゃんとしたメッセージ表示。

例：
・「ドロー！」
・「召喚！」
・「ソウルフュージョン！」
・「ATK 180 VS DEF 120」
・「撃破！」
・「ターンエンド」
・「勝利！」

・大きく、短く、分かりやすく
・必要ならキャラクターアイコンを添える
・画面下または中央下で邪魔になりすぎない位置に表示

==================================================
■演出品質について
==================================================
以下を積極的に活用して完成度を上げること。

・パーティクル
・発光
・加算エフェクト
・軽いカメラズーム
・衝撃波
・台座ライト
・速度線
・残像
・ホログラム線
・属性色エフェクト
・軽いスクリーンシェイク
・ボタン押下時の反応
・手札選択時の浮き上がり
・着地時の影/反発感

ただし、
見づらいほど派手にしすぎないこと。
操作感と視認性は常に最優先。

■実装時のお願い
==================================================
・UI/演出に強くこだわってください
・「動けばOK」ではなく「遊びたくなる見た目」にしてください
・安っぽいフラットUIではなく、高品質で気持ちいいスマホゲームらしさが必要です

・フェイズが地味にならないようにすること
・HOMEでのカスタマイズ導線も分かりやすくしてください
